Limpar todos os desenhos de uma vez

Branch feature/limpar-desenhos, a partir de upstream/main 45b1b81. Sem commit (fica para o orquestrador).

O que mudou

  • A barra de desenho ganhou o botão Limpar tudo (lixeira), logo depois do Desfazer, com aria-label="Limpar todos os desenhos" e a dica “Limpar tudo: apaga todos os traços de uma vez (o Desfazer traz todos de volta)”.
  • Fica desabilitado sem traço. Não há diálogo de confirmação: limpar é um passo só do histórico, e um Desfazer (botão, Ctrl+Z ou ⌘Z) traz todos os traços de volta.
  • Canvas: o passo vai pelo mesmo registrar dos outros (guarda o antes, mostra vazio e grava no layout com salvarDesenho([])).
  • Página do artefato (tela cheia): o passo vai pelo mesmo mudar do hook useDesenhoDoArtefato; a largura guardada do primeiro traço volta a nula (a página flui de novo, como quando a borracha apaga o último) e a gravação no servidor vai com { tracos: [], largura: null }, então a página reaberta não traz os traços de volta. O Desfazer restaura os traços e a largura.
  • A página do artefato não precisou de mensagem nova: o estado do desenho mora no app e a página recebe a lista inteira a cada mudança (desenhoNaPagina.ts segue igual). A mensagem { desenho: "tecla", tecla: "desfazer" } continua só repassando o Ctrl+Z de dentro da página.

Ressalvas

  • Sem captura de tela: não há Playwright nem Puppeteer instalados e o canvas precisa do servidor; com outro orquestrador rodando no Mac de 16 GB, preferi não subir app e Chromium. A ilustração acima usa os ícones reais.
  • Os avisos de act(...) que aparecem na saída do NoArtefato.test são antigos; os testes novos não geram nenhum.
  • O desfazer do canvas guarda no máximo LIMITE_DO_DESFAZER passos, como já era; o limpar ocupa um só.
  • Não há outro lugar com desenho usando a barra: a prévia de site (navegador no canvas) não tem desenho próprio; o que aparece sobre ela é a camada do canvas, que já ganhou o botão.
